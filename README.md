# 7-Link Articulated Robot Arm: SolidWorks Model and ROS Package

Case study, M.Eng. Mechatronics and Cyber-Physical Systems,
Technische Hochschule Deggendorf (2024).

Team project with Sai Krishna Gamini, Harish Chukkala And Vijay. 

## What it is
A 7-link articulated robot arm, modeled in SolidWorks and exported
as a ROS URDF package.

## My part
- Modeled the base and the 7 links in SolidWorks
- Set up the joint axes and coordinate systems in the assembly
- Exported the model to URDF using the SW2URDF add-in
- Visualized the arm in RViz and moved its joints with slider controls
